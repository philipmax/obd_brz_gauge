# 使用指南

[English](USER_GUIDE.en.md) | 简体中文

编译烧录见 [FLASH.md](FLASH.md)，连不上先看 [TROUBLESHOOTING.md](TROUBLESHOOTING.md)。

## 首次开机

1. 上电后先显示 Sky Gauge Logo，随后按设置的开机模式进入（默认 RACE 动画，可关）
2. 第一次使用先进 **设置页**（版本页下滑）：
   - **VEHICLE** 滚轮选你的车型（立即生效，不用重启）
   - **BOOT PAGE** 选开机默认停留的页面
3. 到 **版本页上滑进入 BLE SCAN**，扫描并选中你的 ELM327 BLE 适配器
4. 连接成功后仪表自动初始化（自动协议检测见 [TROUBLESHOOTING.md](TROUBLESHOOTING.md#协议自动检测)），数据开始刷新

之后每次上电仪表会自动回连上次的适配器（记忆 BLE 名称 + MAC），数据中断也会自愈重连，
正常情况下**上车通电即可，无需任何手动操作**。

## 页面导航

仪表主界面是一个**轮播环**，左右滑动切换，环上的页面（左滑 = 下一页）：

```
        ┌──────────────────────────────────────┐
        │  GEAR → RPM → SPEED → TEMP → INFO →  │
        │  NEEDLE → CHART → 版本页 → (回到 GEAR)│
        └──────────────────────────────────────┘
```

| 页面 | 显示内容 | 下滑进入的子页 |
|------|----------|----------------|
| GEAR | 挡位（大字）+ 转速 | 运行时主题表盘页（仅加载了带页面的主题分区主题时出现）|
| RPM | 转速弧 + 超限红色闪烁 | RPM 报警阈值 / 闪烁开关 |
| SPEED | 车速 + 里程统计（运行时累计）| — |
| TEMP | 水温 / 油温 / 进气温（可自定义映射）| 3 行数据项映射配置 |
| INFO | 多格信息面板（可自定义映射）| 5 格数据项映射配置 |
| NEEDLE | 指针表（下滑切数据源）| 指针页数据源选择 |
| CHART | 曲线页（刹车温度并入此页）| 下滑曲线源配置 / **上滑报警阈值** |
| 版本页 | 固件 build tag、BLE 连接状态与设备名 | 见下方隐藏入口 |

**版本页是功能枢纽**：

- **上滑** → BLE SCAN（连接 OBD 适配器；从表角色时兼作 FIND MASTER 扫描）
- **下滑** → 设置页
- **OTA 按钮** → OTA 升级模式（见 [FLASH.md](FLASH.md#app-ota-升级双槽回滚)）
- 左右滑 → 回到仪表环

**隐藏入口**：

- **Logo 页双击** → OBD 协议选择滚轮（**长按 2 秒**保存并重启；协议 0 = 自动检测）
- **版本页快速连点 10 次** → 展厅演示模式（扫表动画）

数据超时或蓝牙断开时，仪表页会显示 **NO SIGNAL** 提示。

## 设置页

| 设置项 | 说明 |
|--------|------|
| BOOT PAGE | 开机默认页（TEMP / INFO / CHART / NEEDLE / GEAR / RPM / SPEED）|
| VEHICLE | 17 个车型配置，切换立即生效（影响挡位识别、油温策略、协议锁定等）|
| THEME | 编译期内置主题（default / amber / ocean 及社区主题），选中后**自动重启生效** |
| 亮度 | 10–100% |
| RACECHRONO | ON=完整 BLE 服务（RaceChrono + 配对）；OFF=最小模式（主表只保留配对服务并广播，其他角色不开 BLE 服务、不广播），省内存 |
| 下滑 → MULTI-GAUGE | 三连表角色设置（见下）|

所有设置存 NVS 断电不丢。里程 / 行程统计只在本轮通电内累计，重启清零。

## 三连表（ESP-NOW 联动）

一块 ELM327 适配器只允许一个蓝牙客户端，所以多块表采用**一主多从**：

- **主表（MASTER）**：保持 BLE + ELM327 连接读数据，通过 ESP-NOW 广播解析后的数据
- **从表（SLAVE）**：只收广播渲染，零额外 OBD 负载
- **独立模式（默认）**：不启用 ESP-NOW

三块板烧同一份固件，角色在 **设置页 → 下滑 → MULTI-GAUGE** 里选（重启生效）。

**配对流程**（真蓝牙配对，不是盲收广播）：

1. 主表设为 MASTER，开始广播 `SkyGauge-XXYY`（XXYY 为设备后缀，多车同场不冲突）
2. 从表设为 SLAVE；未配对过时开机会直接进入 **FIND MASTER** 扫描页
3. 在列表里选中要跟随的主表，完成绑定（记忆主表 MAC，之后每次开机自动跟随）

三连表还支持**联动转速报警**：超阈值时三块表按表位依次亮起再全体闪烁
（RPM 报警页里可开关 Linked 模式），以及开机 "RACE / AS / ONE" 同步动画。

## 开机动画

设置三种模式（NVS `intro_enable`）：

| 模式 | 效果 |
|------|------|
| OFF | 跳过动画直接进仪表 |
| RACE | 内置 "RACE AS ONE" 动画（三连表同步）|
| VIDEO | 播放 `bootmedia` 分区里的自制动画（用手机 App 上传，见 [FLASH.md](FLASH.md#app-ota-升级双槽回滚)）|

自制动画要求：360×360 画布、1:1 比例、注意圆屏四角裁切；设备端更新是事务式的，
上传中断不会破坏现有动画。

## 手机 App 升级

配套 App（`android_app/app-debug.apk`）支持三种推送，都需要先在仪表
**版本页 → OTA 按钮** 进入 OTA 模式：

- **固件升级**：手机连仪表 WiFi 热点（`OBD-Gauge-OTA-XXXX`，密码 `88888888`）高速传输，
  写入备用 OTA 槽；新固件启动 15 秒自检通过才标记有效，失败自动回滚
- **开机动画**：App 内裁切视频、编码后上传
- **主题包**：推送运行时主题到 theme_0 分区（见 [THEMES.md](THEMES.md)）

设备通过 `GET /ota/info` 暴露硬件 / 构建信息，App 刷写前自动做兼容校验，
硬件不匹配会拒绝刷写。协议细节见 [APP_PROTOCOL.md](APP_PROTOCOL.md)。

## 外接传感器（可选）

| 传感器 | 接法 | 说明 |
|--------|------|------|
| RS485 刹车温度 | GPIO13（TX）/ GPIO12（RX），9600 baud，Modbus RTU | 数据并入 CHART 曲线页；刹车温度报警 30 秒节流一次 |
| ADS1115 油压 | I2C，仅 V1 微雪板 | Supra A90 / BMW E 等车型可由 OBD 直读油压 DID 替代 |

排障分别见 [TROUBLESHOOTING.md](TROUBLESHOOTING.md) 对应章节。
